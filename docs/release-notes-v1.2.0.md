# v1.2.0 发布说明

## 🎨 界面改版

- **窗口铺满、三段式布局**：去掉页面内的“假窗口”和重复标题栏；窗口改为 780×560，在 1366×768 / 125% 缩放的笔记本上也能完整显示，内容不再被裁切
- **跟随系统暗色模式**；统一 SVG 图标替换 Emoji；Windows 原生字体（Segoe UI Variable / 微软雅黑 UI）
- **高清 Fluent 多尺寸图标与任务栏图标修复**：重绘抗锯齿翠绿渐变双星芒图标（标准 `16/24/32/48/64/128px` 32-bit BGRA BMP/DIB + `256px` PNG），并在启动时显式绑定 Win32 `WM_SETICON(ICON_BIG / ICON_SMALL)` 与 `GCLP_HICON`，彻底解决便携版 `.exe` 在 Windows 11 任务栏退化为默认空窗口图标的问题
- **应用内对话框**替代浏览器 `alert / confirm`（不再出现“tauri.localhost 显示”）
- **下载页**：实时速度与剩余时间；暂停后进度条变灰；「更改…」调用系统文件夹选择器
- **欢迎页**：自动检测本机安装状态与云端版本，主按钮随之变为「开始安装 / 开始更新 / 重新安装」
- **步骤条**新增出错状态（出错步骤标红）；每页只保留一个主按钮
- UAC 提示只在真正需要提权时出现；普通权限安装时「整机预置」标记为已跳过

## 🐛 修复

- **ARM64 设备下载了 x64 安装包**：改为运行时检测原生架构（`IsWow64Process2`）
- **下载未完成也能点「下一步」**，进入校验后报错、重试又报 BUSY
- **快速暂停→继续报 BUSY**：等工作线程真正退出后才允许继续
- **错误页无法离开**：「完成」按钮无反应、「上一步」进入无按钮的安装页
- **下载目录为盘符根目录（如 `D:\`）时提权参数被破坏**：按 Windows 命令行规则转义结尾反斜杠
- **提权后续跑动作可能丢失**：改为前端加载完成后主动领取
- **卸载确认框“取消=保留数据”易误操作**：改为勾选框 + 明确的「卸载 / 取消」
- **安装记录 ETag 从未保存成功**（下载完成时被提前删除），导致检查更新的 ETag 回退逻辑失效
- **目录残留旧版完整安装包时会被直接安装**：现与云端版本对比，过期则重新下载
- **无 ETag 记录的旧分片续传可能拼接新旧版本**：改为从头下载
- 校验失败后「重试」会删除本地包并重新下载（之前会反复校验同一个坏文件）
- UAC 被取消时明确提示，可重试；成功时旧进程立即退出交接（不再靠 `taskkill`）
- 版本号与 Release 对齐（此前配置中仍为 0.1.0）

## 🔒 安全与稳健性

- 发布者改为**精确匹配** `CN=`，并新增**颁发者校验**（须为 Microsoft Corporation）
- 管理员检测、磁盘空间、CPU 架构改用 Win32 API，环境检测不再连开多个 PowerShell；网络检测并行执行
- 签名信息一次 PowerShell 调用取全（原来 2 次）
- **单实例**：重复双击聚焦已有窗口，避免两个进程写同一个下载分片
- **诊断日志落盘**（`installer.log`，自动滚动），提权前后的日志都能复制
- 前端脚本外置，CSP 去掉 `script-src 'unsafe-inline'`；动态内容统一转义

## 🔧 工程

- CI：推送 / PR 自动跑 `cargo fmt --check`、`clippy -D warnings`、单元测试；构建改用预编译 Tauri CLI（省去数分钟源码编译）；tag 与配置版本不一致时拒绝发布
- 新增单元测试：版本比较、部署错误码映射、命令行 / PowerShell 引用、证书 DN 匹配、清单解析
- 合并重复的 PowerShell 调用代码（`ps.rs`）；移除仓库中的内部打 tag 脚本
