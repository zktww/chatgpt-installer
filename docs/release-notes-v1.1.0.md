## ✨ 新增：检查更新

- **欢迎页新增「检查更新」入口**：安装成功后，工具会把安装包的版本与 ETag 记录在 `settings.json`；以后打开欢迎页点一下，即可对比官方 CDN 是否有新版，有新版一键跳转下载重装
- **官方版本号精确对比**：以 OpenAI 官方 CDN 的 `x-ms-meta-package_version` 为准做四段语义对比（云端版本 > 本机版本才提示更新），ETag 降级为回退方案——判断准、不再每次重跑都全量下载 800MB
- **版本漂移检测**：若本机 ChatGPT 版本与本工具上次安装记录不一致（例如曾从微软商店或其他渠道更新过），如实提示"其他渠道更新不受本工具控制"，不误判、不瞎报
- **升级语义说明**：Windows 的 `Add-AppxPackage` 原生就是覆盖升级，重跑一遍工具即完成升级；若已安装版本比下载包还新，会报 `0x80073D06`，工具已映射为「已安装更新版本的 ChatGPT，无需重复安装」
