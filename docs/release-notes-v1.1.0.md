# v1.1.0 发布说明

## ✨ 新增：检查更新

- **欢迎页新增「检查更新」入口**：安装成功后，工具会把安装包的版本与 ETag 记录在 `settings.json`；以后打开欢迎页点一下，即可对比官方 CDN 是否有新版，有新版一键跳转下载重装
- **官方版本号精确对比**：以 OpenAI 官方 CDN 的 `x-ms-meta-package_version` 为准做四段语义对比（云端版本 > 本机版本才提示更新），ETag 降级为回退方案——判断准、不再每次重跑都全量下载 800MB
- **版本漂移检测**：若本机 ChatGPT 版本与本工具上次安装记录不一致（例如曾从微软商店或其他渠道更新过），如实提示"其他渠道更新不受本工具控制"，不误判、不瞎报
- **升级语义说明**：Windows 的 `Add-AppxPackage` 原生就是覆盖升级，重跑一遍工具即完成升级；若已安装版本比下载包还新，会报 `0x80073D06`，工具已映射为「已安装更新版本的 ChatGPT，无需重复安装」

## 🐛 修复

- **下载状态卡"进行中"**：下载目标解析失败时未复位状态，之后每次点下载都报 BUSY
- **路径含空格时提权失败**：提权参数拼接未加引号，`D:\My Downloads` 这类目录会被拆散
- **UAC 点"否"程序直接退出**：改为提权成功后新进程结束旧进程；点"否"则原进程继续存活，可重试
- **慢速下载被 30 秒超时掐断**：reqwest 默认 30 秒总超时，800MB 下载改用不限时（HEAD 请求单独 15 秒）
- **跨用户提权数据错位**：用另一管理员账号提权时，设置/安装记录/数据清理会作用到管理员账号，现透传原用户目录
- **管理员检测不可靠**：`net session` 依赖 LanmanServer 服务，改为 token 管理员检测
- **路径含 `[ ]` 校验/安装失败**：签名校验改用 `-LiteralPath`，安装路径做通配符安全转义
- **磁盘检测查错盘**：改为按实际下载目录所在盘检测，而非只查系统盘
- **暂停会进失败页**：暂停与取消分离，暂停显示"已暂停"状态，进度保留可继续
